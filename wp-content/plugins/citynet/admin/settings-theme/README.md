# تم اختیاری تنظیمات سیتی‌نت

ظاهر جدید پیش‌فرض است. دکمهٔ «بازگشت به ظاهر قدیمی» ظاهر قدیمی را فعال می‌کند و دکمهٔ «تم جدید افزونه» دوباره ظاهر جدید را برمی‌گرداند. انتخاب ظاهر با کوکی `cn_settings_theme` در مسیر ادمین همین سایت، برای یک سال در همین مرورگر نگهداری می‌شود؛ انتخاب قبلی ظاهر قدیمی حفظ می‌شود و هیچ گزینه‌ای در دیتابیس افزونه تغییر نمی‌کند.

تمام فایل‌های PHP، CSS، JavaScript و تست‌های مربوط به ظاهر جدید در همین پوشه هستند. برای حذف این قابلیت، فقط پوشهٔ `admin/settings-theme` را حذف کنید. بارگذاری پوشه اختیاری است و نبودن آن، حتی با کوکی فعال، ظاهر اصلی را برمی‌گرداند. ویرایش فایل دیگری لازم نیست.

فایل‌های اصلی `admin/admin-menu.php`، `admin/css/cn-admin.css` و `admin/js/cn-admin.js` و فایل‌های `includes/api.php` مربوط به عملکرد اصلی و مدیریت خطای API هستند و جزو این تم نیستند.

تغییر ظاهر باعث بارگذاری مجدد صفحه می‌شود. اگر فرم تغییرات ذخیره‌نشده داشته باشد، دکمه ابتدا پیام ذخیره نمایش می‌دهد. نام، ترتیب و محل فیلدها در تب‌های اصلی حفظ می‌شود.

برای بررسی ناوبری با jQuery و ACF نصب‌شده، با فراهم بودن `jsdom` در `NODE_PATH` اجرا کنید:

```text
node admin/settings-theme/tests/admin-layout-regression.js
node admin/settings-theme/tests/theme-switch-regression.js
```
