ساخت نوشته‌های آزمایشی فارسی گردشگری برای post type پیش‌فرض وردپرس، همراه با متن کامل، دسته‌بندی، برچسب و تصویر شاخص.

== Description ==

این افزونه از مسیر «ابزارها ← داده‌ساز گردشگری» نوشته‌های واقع‌نمای فارسی برای آزمایش قالب، آرشیو، صفحه اصلی، جست‌وجو و چیدمان سایت ایجاد می‌کند.

ویژگی‌ها:

* تولید نوشته با post type داخلی `post`
* عنوان، خلاصه و متن چندبخشی فارسی
* دسته مادر «گردشگری» و هشت دسته فرزند
* برچسب مقصد، استان و نوع سفر
* تصویر شاخص واقعی و محلی؛ بدون وابستگی به دانلود زمان اجرا
* تاریخ انتشار تصادفی در بازه انتخابی
* حالت پیش‌نویس یا انتشار مستقیم
* جلوگیری از تکرار تا حد ممکن با کلیدهای یکتا
* حذف امن فقط برای داده‌هایی که افزونه ساخته است
* نگه‌داشتن دسته یا برچسبی که روی محتوای دیگر استفاده شده باشد

هر اجرا حداکثر ۲۰ نوشته می‌سازد تا پردازش رسانه روی هاست‌های اشتراکی پایدارتر بماند.

== Installation ==

1. فایل ZIP افزونه را از بخش «افزونه‌ها ← افزودن افزونه تازه ← بارگذاری افزونه» نصب کنید.
2. افزونه را فعال کنید.
3. به «ابزارها ← داده‌ساز گردشگری» بروید.
4. تعداد، وضعیت انتشار و بازه تاریخ را انتخاب کنید.
5. دکمه «ساخت نوشته‌های گردشگری» را بزنید.

پیشنهاد می‌شود اجرای اول را با ۵ نوشته و وضعیت «پیش‌نویس» انجام دهید.

== Frequently Asked Questions ==

= آیا افزونه Custom Post Type می‌سازد؟ =

خیر. خروجی دقیقاً روی post type پیش‌فرض وردپرس یعنی `post` ساخته می‌شود.

= آیا برای تصویرها به اینترنت نیاز است؟ =

خیر. تصاویر CC0 داخل بسته افزونه قرار دارند و هنگام ساخت نوشته به کتابخانه رسانه وردپرس منتقل می‌شوند.

= حذف داده‌ها به نوشته‌های واقعی سایت آسیب می‌زند؟ =

افزونه فقط مواردی را حذف می‌کند که با متادیتای داخلی مخصوص خودش علامت‌گذاری شده‌اند. دسته یا برچسب ساخته‌شده توسط افزونه نیز فقط زمانی حذف می‌شود که خالی باشد.

= چرا هر بار فقط ۲۰ نوشته ساخته می‌شود؟ =

ساخت تصویر بندانگشتی روی برخی هاست‌ها زمان‌بر است. محدودیت ۲۰تایی احتمال خطای زمان اجرا و مصرف حافظه را کاهش می‌دهد. عملیات را می‌توان چند بار تکرار کرد.
