# مرجع `inc/security.php`

[مشاهدهٔ فایل منبع](../../inc/security.php)

این فایل تنظیمات امنیتی فرانت‌اند را با callbackهای بدون نام ثبت می‌کند:

- حذف نسخهٔ وردپرس از head و feedها؛
- نمایش پیام ثابت برای خطای نام کاربری یا رمز عبور؛
- بستن REST users برای کاربران مهمان؛
- تبدیل author archive مهمان به 404 واقعی و بدون cache؛
- حذف users provider از sitemap هستهٔ وردپرس.

دسترسی REST کاربر واردشده دست‌نخورده می‌ماند تا ویرایشگر و افزونه‌ها کار کنند.
